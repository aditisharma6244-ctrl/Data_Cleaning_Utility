# Data Cleaning Utility

## 📌 Project Overview

This project is a **Data Cleaning Utility** developed as part of the **Syntecxhub Data Science Internship – Task 1**.

The project uses Python, Pandas, and NumPy to identify and handle common data-quality problems such as missing values, incorrect data types, invalid values, duplicate records, and inconsistent column names.

## 🎯 Objectives

* Detect missing values
* Handle missing values
* Fix incorrect data types
* Parse date values
* Handle invalid values
* Remove duplicate records
* Standardize column names
* Standardize inconsistent values
* Generate a cleaned dataset
* Generate a cleaning log
* Generate a cleaning summary

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Google Colab
* Jupyter Notebook

## 🔄 Data Cleaning Process

The project follows these steps:

1. Create and inspect the dataset
2. Detect missing values
3. Handle missing values
4. Convert incorrect data types
5. Parse date values
6. Handle invalid Age values
7. Standardize Department values
8. Remove duplicate records
9. Standardize column names
10. Save the cleaned dataset
11. Generate a cleaning log
12. Generate a cleaning summary
13. Perform a final quality check
